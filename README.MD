# FSOCIETY Music Player

A dark-themed desktop music player built with Python and Tkinter, featuring a red-and-black FSOCIETY-inspired interface.

## Features

- Dark terminal-inspired interface
- HOME, NOW PLAYING, LIBRARY and PLAYLIST navigation
- Add local audio files using a file selector
- Supports MP3, WAV and OGG file selection

## Technologies

- Python
- Tkinter
- Pygame CE

## Requirements

- Python 3.14 or a compatible Python version
- pygame-ce

## Installation

Install the required dependency:

```bash
py -m pip install pygame-ce
```

## Run the application

Navigate to the project folder and run:

```bash
py main.py
```

## Project Status

This is an early version of the project. The current version includes the graphical interface and audio file selection. Music playback and additional player features are planned for future development.
